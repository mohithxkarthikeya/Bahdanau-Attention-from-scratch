# Credits

- Paper: Bahdanau, Cho and Bengio, [Neural Machine Translation by Jointly Learning to Align and Translate](https://arxiv.org/abs/1409.0473) (2014). arXiv 1409.0473.

- Data: [Multi30k] (https://huggingface.co/datasets/bentrevett/multi30k) (English-German image caption translations), text-only copy from the Hugging Face dataset bentrevett/multi30k.
